## 클라우드 컴퓨팅이란?

> ‘구름’ 비유의 기원 (출처: ‘클라우드 세상 속으로’-조시 로젠버그, 아서 마테오스)
> 

10여 년이 넘는 기간 동안, 애플리케이션의 아키텍처를 그림으로 그릴 때, 인터넷에 들어가야 하는 경우, 사람들이 항상 인터넷을 구름으로 표현함. →여기서 기원

익명의 사용자들이 브라우저를 통해서 인터넷에 접속하고 그 브라우저가 웹사이트를 찾아가서 그 사이트의 인프라와 애플리케이션에 접근하기 시작하는 것을 형상화하기 위해 사용되고 있음. 

> 클라우드의 진화과정
> 

최초의 클라우드 개념: 사용자들이 브라우저를 통해 인터넷에 접근하는 것, 즉 인터넷에 연결된 수많은 컴퓨터의 집합

> 클라우드 컴퓨팅의 다섯 가지 핵심 원칙
> 
- 구매자라면 누구나 사용할 수 있는 공유된 컴퓨팅 자원
- 하드웨어 사용을 극대화하기 위한 가상화된 컴퓨팅 자원
- 필요에 따라 규모를 늘리거나 줄일 수 있는 탄력성
- 자동화된 가상머신 생성과 제거
- 사용한 자원만큼 지불하는 과금 체계

> 클라우드 전환으로 얻는 이익
> 
1.  경제적 이점
    
    클라우드 컴퓨팅은 서버와 저장장치를 직접 구매하지 않아도 되기 때문에 초기 구축 비용을 크게 줄일 수 있다.
    
    또한 사용한 만큼만 비용을 지불하는 과금 방식(Pay-as-you-go)을 사용하여 불필요한 지출을 줄일 수 있다.
    
    예시
    
    - 기업이 고가의 서버를 직접 구매하지 않고 필요한 만큼만 임대하여 사용 가능
    - 유지보수 비용 및 전력 비용 절감 가능
2. 민첩성의 이점
    
    클라우드는 서버 구매 및 설치 과정 없이 빠르게 서비스를 구축하고 확장할 수 있다.
    
    필요한 순간 즉시 서버를 생성하거나 제거할 수 있어 변화에 빠르게 대응 가능하다.
    
    예시
    
    - 트래픽 증가 시 서버를 즉시 확장 가능
    - 새로운 서비스를 빠르게 배포 가능
3.  경쟁우위를 위한 효율성
    
    클라우드는 기업이 IT 인프라 관리보다 핵심 서비스와 아이디어 개발에 집중할 수 있도록 도와준다.
    
    이를 통해 서비스 개발 속도를 높이고 경쟁력을 강화할 수 있다.
    
    예시
    
    - 스타트업이 인프라 구축보다 서비스 개발에 집중 가능
    - 빠른 기능 업데이트 및 서비스 개선 가능
4. 우수하고 강력한 보안
    
    클라우드 서비스 제공 업체는 전문적인 보안 시스템과 지속적인 관리 체계를 제공한다.
    
    데이터 암호화, 접근 제어, 자동 백업 등을 통해 안정적인 데이터 보호가 가능하다.
    
    예시
    
    - 데이터 자동 백업 및 복구 지원
    - 해킹 및 보안 위협 대응 시스템 운영
    - 사용자 권한 관리 기능 제공

클라우드 서비스는 제공 범위에 따라 크게 **IaaS, PaaS, SaaS**의 3가지 계층으로 분류된다.

---

1. IaaS (Infrastructure as a Service)
    
    서버, 저장공간, 네트워크 등 IT 인프라를 인터넷을 통해 제공하는 서비스.
    
    사용자가 운영체제와 프로그램을 직접 설치하고 관리할 수 있다.
    
    - 가상 서버 제공
    - 높은 자유도
    - 직접 서버 관리 가능
    
    장점
    
    - 필요한 만큼 인프라 사용 가능
    - 서버 구매 비용 절감
    
    단점
    
    - 사용자가 서버를 직접 관리해야 함
2. PaaS (Platform as a Service)
    
    애플리케이션 개발 및 배포 환경을 제공하는 서비스.
    
    개발자는 서버 관리 없이 프로그램 개발에 집중할 수 있다.
    
    - 개발 환경 제공
    - 운영체제 및 서버 관리 자동화
    - 빠른 배포 가능
    
    장점
    
    - 개발 속도 향상
    - 유지보수 부담 감소
    
    단점
    
    - 플랫폼 환경에 제약이 있을 수 있음
3.  SaaS (Software as a Service)
    
    소프트웨어를 인터넷을 통해 바로 사용할 수 있도록 제공하는 서비스.
    
    사용자는 설치 없이 웹 브라우저만으로 서비스를 이용할 수 있다.
    특징
    
    - 설치 필요 없음
    - 인터넷만 있으면 사용 가능
    - 사용자가 유지보수 불필요
    
    장점
    
    - 사용이 간편함
    - 접근성이 높음
    
    단점
    
    - 인터넷 연결 필수
    - 사용자 맞춤 설정 제한 가능

계층별 비교

| 구분 | IaaS | PaaS | SaaS |
| --- | --- | --- | --- |
| 제공 범위 | 인프라 | 개발 환경 | 소프트웨어 |
| 사용자 관리 범위 | 많음 | 중간 | 거의 없음 |
| 사용 대상 | 시스템 관리자 | 개발자 | 일반 사용자 |
| 대표 예시 | AWS | Vercel | Google Docs |

## 서버와 클라우드 차이

(출처: [https://www.samsungsds.com/kr/cloud-glossary/difference-cloud-storage-server-drive.html](https://www.samsungsds.com/kr/cloud-glossary/difference-cloud-storage-server-drive.html))

서버는 원래 특정 기능을 수행하는 컴퓨터나 시스템을 뜻하고, 보통 물리적으로 직접 보유하거나 관리합니다. 반면 클라우드는 서버를 포함한 여러 IT 자원을 인터넷 기반으로 제공하는 개념입니다. 즉, 서버는 **하드웨어나 시스템 자체**에 가깝고, 클라우드는 **그 자원을 제공하는 방식과 환경**이라고 이해하면 쉽습니다.

- 서버(Server)란?
    
    서버는 데이터를 저장하고 사용자에게 서비스를 제공하는 컴퓨터
    
    웹사이트 접속, 파일 저장, 게임 접속 등의 기능을 수행
    
- 클라우드(Cloud)란?
    
    클라우드는 인터넷을 통해 서버, 저장공간, 소프트웨어 등을 필요한 만큼 빌려 사용하는 기술
    

비교하면 다음과 같습니다.

| **항목** | **일반 서버** | **클라우드** |
| --- | --- | --- |
| 설치 방식 | 직접 구매, 설치, 관리 | 인터넷으로 접속해 사용 |
| 비용 | 초기 투자비가 큼 | 사용한 만큼 지불하는 경우가 많음 |
| 확장성 | 확장에 시간과 비용이 듦 | 필요할 때 빠르게 늘리거나 줄일 수 있음 |
| 유지보수 | 사용자가 직접 부담 | 제공업체가 많은 부분을 관리 |
| 접근성 | 내부 네트워크나 지정 환경 중심 | 어디서나 접속 가능 |

클라우드 서버는 물리적 서버의 자원을 가상화해 인터넷으로 접근하는 형태이므로, 기존 서버보다 관리가 편하고 확장도 쉽습니다.
